📖 About EduPredict AI

EduPredict AI is a Machine Learning web application that predicts a student's expected examination score using study habits, attendance, previous academic performance, sleep schedule and sample paper practice. The project is developed using Python, Flask, HTML, CSS, JavaScript and Scikit-learn.
